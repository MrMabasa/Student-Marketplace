# Student Marketplace

## 1. Project Overview
Student Marketplace is an Android application designed to help students buy and sell items within their student community.

## 2. Technology Stack
- Kotlin
- XML layouts
- Android Studio
- Gradle

## 3. Current Development Progress
- Android project foundation created.
- Navigation between initial screens implemented.
- Welcome, Sign In and Register screens created.
- Home, Browse Listings, Listing Details and Create Listing screens created.
- Brand colours and reusable button styles implemented.

## 4. Version Control
Git and GitHub are used to manage the source code and track development progress.

GitHub Actions will be configured for automated building and testing.

## 5. Planned Features
- Secure student registration and login.
- Single Sign-On (SSO).
- Marketplace listings and search.
- REST API and database integration.
- Offline functionality and synchronisation.
- Push notifications.
- South African language support.
- User settings and preferences.

## 6. Release Notes
Development is ongoing. Completed features and updates will be documented here as the application progresses.
